O que é o Vibe Coding Security Scanner?

O Vibe Coding Security Scanner da TAVARDT é uma solução defensiva desenvolvida para a auditoria perimetral passiva de aplicações web concebidas com recurso a ferramentas de IA generativa (Cursor, Lovable, Bolt.new, v0). O scanner realiza a identificação de credenciais expostas no cliente, validação de regras de RLS no Supabase e verificação de sourcemaps públicos.

Vetores de Risco Críticos em Aplicações Geradas por IA

Credenciais de API Expostas no Cliente

Ferramentas de IA compilam com frequência chaves privadas da OpenAI, Stripe e Resend em pacotes do cliente através de variáveis públicas.

Falhas de RLS no Supabase / Firebase

Bases de dados geradas sem regras de Row Level Security permitem a extração direta de dados sensíveis por terceiros sem autenticação.

Exposição de Ficheiros Sourcemap (.js.map)

Ficheiros de depuração deixados ativos em produção viabilizam a leitura integral do código-fonte e lógica de negócio.

Cabeçalhos de Segurança Inexistentes

A ausência de CSP e proteção de enquadramento facilita ataques de injeção XSS e manipulação da interface.

Perguntas Frequentes (FAQ) & Diretrizes de Cibersegurança

De que forma o vibe coding afeta a segurança da aplicação?
Os modelos de IA priorizam a interface e funcionalidade imediata, negligenciando a separação segura entre cliente e servidor e expondo permissões críticas.
O Vibe Coding Security Scanner armazena informação da auditoria?
Não. O processo é inteiramente passivo e executado em tempo real, sem gravação de registos, histórico ou dados das aplicações submetidas.
Como salvaguardar credenciais de terceiros no cliente?
Todas as comunicações com APIs externas devem transitar por um serviço de backend ou edge computing seguro, impedindo o acesso do navegador a chaves privadas.
Por que razão as políticas de RLS do Supabase falham em código de IA?
As instruções em linguagem natural frequentemente criam esquemas sem ativar as diretivas de isolamento de linhas no PostgreSQL, permitindo acessos indiscriminados.
Qual o apoio disponibilizado pela equipa de engenharia da TAVARDT?
A TAVARDT executa o isolamento de credenciais, configuração de regras de segurança no Supabase e reforço perimetral Cloudflare sem interrupção de serviço.
